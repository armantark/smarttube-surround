# SmartTube rear-speaker patch

A patched build of SmartTube for the owner's Sony TV that plays stereo YouTube sound from the
soundbar's rear speakers too, rebuilt automatically after each upstream SmartTube release.

## Language

**Stereo-to-rear**:
Playing a stereo track as 5.1, with the left and right channels also sent to the rear speakers.
_Avoid_: Upmix (the soundbar's own upmix sends only room sound to the rear)

**Upstream release**:
A release that yuliskov publishes in the SmartTube GitHub repository.
_Avoid_: Official build

**Patched build**:
The SmartTube APK that this project builds from an upstream release plus the stereo-to-rear patch.
_Avoid_: Fork build, custom SmartTube

**Rear speakers**:
The two wireless speakers behind the listener, paired with the HT-A3000 soundbar.
_Avoid_: Surround speakers, back speakers
